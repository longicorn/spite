# 製品要求仕様書 (PRD): Predict

[English Document](prd.md)

`spite predict`は3つの対数正規分布を使って完了期間を予測します。[製品全体のPRD](../prd.ja.md)と[PredictのADR](adr.ja.md)も参照してください。

## 入力

- `--periods`：通常シナリオの最頻値となる正の期間。単位は抽象的なperiodで、中央値ではありません。
- `--actual-periods`：振り返りに使う実績期間。0以上の値を任意で指定します。
- `--days-per-period`：概算日数に換算するための正の倍率。任意指定であり、カレンダーや祝日は計算しません。
- `--best-factor`と`--worst-factor`：各シナリオの最頻値に適用する係数。既定値は0.8と1.5です。
- `--sigma`：正の対数正規分布の形状パラメータ。既定値は0.5です。
- `--format`：`terminal`が既定で、`markdown`も選択できます。`--output`は保存先ルートを指定します。実行ごとのディレクトリに`report.md`と`snapshot.json`を保存し、terminalモードでは`chart.png`も保存します。`--show`は画像を表示し、Markdownとは併用できません。
- `--distribution`：現在は`lognormal`のみを指定できます。

## 出力

各シナリオのP50、P80、P90をperiodで表示します。換算係数を指定した場合は概算日数も併記します。グラフには対数正規分布の確率密度を示します。実績期間を指定すると、通常シナリオの最頻値とP90との差、累積分布上の位置を表示します。P99.9を超える場合は生存関数で残りの確率を示します。

最頻値とシグマからμ = ln(mode) + σ²で分布を決めます。過去の実績による校正と分布の追加は今後の課題です。

3つのシナリオは、最頻値の前提が異なり、同じσを使う条件付き予測です。分布は重なることがあり、ツールはシナリオを確率で重み付けした混合分布にはしていません。シナリオとσは仮定であり、実績で校正された信頼水準ではありません。

当面は全シナリオで同じσを使います。シナリオごとに異なる幅を指定するための校正根拠がないためです。十分な実績が集まったら、共通σとシナリオ別の幅を比較してから既定値の変更を検討します。
