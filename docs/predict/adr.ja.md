## ADR-0001: 対数正規分布と3シナリオ予測モデルの採用

### ステータス
承認済 (Accepted)

### コンテキスト
従来のソフトウェア開発見積もりでは、対称的な不確実性（正規分布など）が暗黙的に仮定されたり、単一の勘や都合による期日が使われることが一般的でした。しかし実際のソフトウェア開発リードタイムは強い右裾（右に歪んだ非対称性）を示します。最短工数には物理的・論理的な限界があり大幅に早く終わることは稀である一方、未知の技術課題や調整遅延によって遅延は大きく長期化しやすいためです。

また、単一の分布のみを提示すると、外部要因（依存関係の早期解消や大幅遅延など）によるシナリオの振れ幅を表現しにくいという課題がありました。

### 決定事項
1. **対数正規分布 (Lognormal Distribution)** をリードタイム予測の基準分布モデルとして採用する。
2. **最頻値 (mode) と $\sigma$ からパラメータを導出する**:
   - ユーザーが入力した想定納期までの稼働日数を分布のピーク（mode）とする。
   - 分布の幅を表す形状パラメータとして既定値 $\sigma = 0.5$ を全シナリオ共通で適用する。
   - パラメータ $\mu$ は以下の関係式より算出する：
     $$\mu = \ln(\text{mode}) + \sigma^2$$
3. **係数による3シナリオ展開**:
   - **最善シナリオ**: $\text{mode}_{\text{best}} = \text{mode}_{\text{nominal}} \times 0.8$
   - **通常シナリオ**: $\text{mode}_{\text{nominal}} = \text{mode}$
   - **最悪シナリオ**: $\text{mode}_{\text{worst}} = \text{mode}_{\text{nominal}} \times 1.5$
4. `scipy.stats.lognorm` を用いて各シナリオのP50（中央値）、P80、P90パーセンタイルを算出する。

### 影響とトレードオフ
- **メリット**: リードタイムの非対称性（開始直後の下限の硬さと右側の長い裾）を自然に表現できる。ユーザーに統計学の複雑な知識を要求することなく、「最善・通常・最悪」という直感的なシナリオ計画を提示できる。
- **デメリット・制約**: 既定の係数（0.8, 1.5）および $\sigma = 0.5$ は初期の仮定値であり、複数プロジェクトの実証データに基づく自動校正値ではない。超大規模プロジェクトで観測されるべき乗則（パレート分布）のような極端に重いテールに対しては、対数正規分布単体では過小評価となる可能性がある（将来のスプライス分布検討対象）。

## ADR-0002: 通常シナリオ基準による実績振り返り評価方式の採用

### ステータス
承認済 (Accepted)

### コンテキスト
開発完了後、チームは実際の実績が当初の確率的見通しに対してどのように位置づけられるかを評価する必要があります。Spiteの3シナリオ（最善・通常・最悪）に対して、すべての分布を基準に評価数値を算出すると、評価軸が分散して解釈が困難になります。

また、大幅な遅延が発生した案件では分布の裾（テール）の極端な領域に達するため、通常のパーセンタイル表示だけではその事象の稀少性やリスク度合いが直感的に伝わらない問題がありました。

### 決定事項
1. **通常シナリオ（Nominal）を一元的な評価基準とする**:
   - 振り返りモード（`--actual-end-date` 指定時）において、数値評価（想定納期との差、パーセンタイル、乖離日数）はすべて**通常シナリオ**の分布を基準として算出する。
   - 最善シナリオおよび最悪シナリオはグラフ上の視覚的比較用として残し、個別の評価指標は算出しない。
2. **累積分布関数 (CDF) によるパーセンタイル算出**:
   - 実績稼働日数を通常シナリオのCDFに照らし合わせ、パーセンタイルを算出する。
3. **P90乖離とP99.9超テールの評価**:
   - 通常シナリオのP90期日との差分日数を表示する。
   - 実績がP99.9を超える場合（CDF > 0.999）、「P99.9超相当」と明記し、生存関数 (SF: $1 - \text{CDF}$) を用いてその実績以降に完了する確率を表示する。
4. **単一案件振り返りスコープの限定**:
   - 今回の実装は1件の案件を当初仮定に照らして振り返る機能とし、1件の実績から自動的に係数や分布を自動調整・更新する機構とは切り離す。

### 影響とトレードオフ
- **メリット**: 複数シナリオ間の指標の混乱を避け、単一の基準（当初の通常想定）に対する客観的な評価指標が得られる。極端な遅延（テールリスク）を生存関数によって定量化し、安易に「100%」と丸めずにリスクの深刻さを可視化できる。
- **デメリット・制約**: 振り返り結果が次回の予測パラメータ（$\sigma$ や係数）に自動反映されるわけではなく、複数案件データによるパラメータ校正は今後の課題となる。
