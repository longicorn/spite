確率分布のイメージを掴み触って感覚を掴むのを目的とする
よって、過去データを利用した想定は行わない

### 1. 分布の種類を以下から決定する

以下のコマンドで処理を行う

```
$ spite predict
```

#### 処理1: 分布の選択
ユーザが以下の分布を選択する

- 対数正規分布: 標準的な開発、または初期開発に適応する
- 対数正規分布とGPDまたはParetoを組み合わせたスプライス分布 : 開発が泥沼化した/しやすい現場の場合
- Weibull分布 : テスト工程やバグ収束予測に適応する

#### 処理2: パラメータ決定方式の選択
確率分布を計算するために以下の2パターンのどちらかをユーザが決定する

- 選択肢1: 開発開始日、納期、最悪でもこの日(P90相当)には終わる/終えたい日の決定
- 選択肢2: 開発開始日のみ決定して確率分布を標準的な形で計算する

#### 処理3: 計算とグラフ化
上記変数を用いて、確率分布を計算しグラフ化する
また表示したい値としてP50・P80・P90、尖度等ソフトウェア開発での目安として利用できそうな代表的な値を表示する

- P50・P80・P90は日数&日付で表示する事
- 一旦祝日は考慮しないが土日を休日として扱う事にするので1週間5日の活動とする
- 選択肢1では比較しやすいように選択肢2のグラフ表示も行う
