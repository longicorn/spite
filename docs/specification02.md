# 仕様書 02: 3シナリオ納期予測

## 目的

`spite predict` で、入力した想定納期を基準に最善・通常・最悪の3つの納期分布を表示する。
初期版では係数による仮定を使い、将来、実績などを使ったシミュレーションに置き換える。

## 入力

```bash
spite predict --start-date YYYY-MM-DD --deadline YYYY-MM-DD [オプション]
```

- `--start-date`: 開発開始日。
- `--deadline`: 想定納期。通常シナリオの分布ピーク(mode)として扱う。
- `--actual-end-date`: 実際の開発終了日。省略時は開発中またはこれから開発する案件として予測し、指定時は終了済み案件として振り返る。開始日以降の日付を指定する。
- `--best-factor`: 最善シナリオの係数。通常期間に掛ける。既定値は `0.8`。
- `--worst-factor`: 最悪シナリオの係数。通常期間に掛ける。既定値は `1.5`。
- `--sigma`: 3シナリオ共通の分布の幅。既定値は現行と同じ `0.5`。
- `--output`, `--show`: グラフの画像保存、または画面表示。

## 予測モードと振り返りモード

- `--actual-end-date` がない場合は、最善・通常・最悪の3シナリオによる予測を行う。
- `--actual-end-date` がある場合も3分布を表示し、実績期間を通常シナリオに照らして評価する。
- 振り返りでは実績期間、当初の想定納期との差(日数・割合)、通常シナリオでのパーセンタイル、P90との差を表示する。
- 実績がP99.9を超える場合は「P99.9超相当」とし、実績以降に完了する確率も表示する。
- 振り返りグラフは実績期間まで横軸を広げ、実績位置に目印を表示する。
- 終了日は想定納期より前でもよい。実際の終了日が開始日より前の場合はエラーとする。

## 計算

- 日数は開始日からの稼働日数(土日を除外、祝日は未考慮)で扱う。
- 通常ピークは開始日から想定納期までの稼働日数。
- 最善ピークは通常ピーク×最善係数、最悪ピークは通常ピーク×最悪係数。
- 各ピークをmodeとし、共通のσを使って対数正規分布を作る。
- 各分布についてP50・P80・P90を計算する。ピークや係数は完了日の保証ではない。

## 出力

- 最善・通常・最悪それぞれの分布を同じグラフに表示する。
- 各シナリオのP50・P80・P90を稼働日数と日付で表示する。
- 振り返り時は、実績の評価を通常シナリオ基準で表示する。最善・最悪分布はグラフ上の比較用とする。
- 画像ファイルを指定しない場合はターミナルにASCIIグラフを表示する。

## 今後

本仕様の係数は初期の仮定であり、利用者が変更できる。将来的には固定係数に頼らず、入力条件や実績を使ったシミュレーションでシナリオを作る。
