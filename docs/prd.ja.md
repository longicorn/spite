# 製品要求仕様書 (PRD): Spite

[English Document](prd.md)

Spiteは、ソフトウェア開発の完了期間を確率分布として予測する実験用ツールです。チームが前提条件を比較し、不確実性を説明するために使います。

[Predict](predict/prd.ja.md)は想定期間を対数正規分布の最頻値として予測し、実績の振り返りにも対応します。[Simulation](simulation/prd.ja.md)は依存関係、人数制限、作業の発見、手戻りをモデル化します。

両機能は抽象的なperiodを使います。1 periodの意味は、例えば1 sprintなど、利用者が決めます。日数への換算係数を任意で指定すると概算日数を表示します。カレンダー日付や祝日は計算しません。詳細は[共通ADR](adr.ja.md)を参照してください。Pointによる作業量のモデル化とプロジェクト実績からの校正は今後の課題であり、現在のシミュレーション入力には含まれません。

[History](history/prd.ja.md)は現在のブランチのGit履歴を観測し、保存した予測と参考比較します。
