# 製品要求仕様書 (PRD): Spite

[English Document](prd.md)

## ビジョン

Spiteは、ソフトウェア開発の納期を確率分布として予測する実験用ツールです。チームが不確実性を伝え、前提条件を比較し、予測と実績を照らし合わせるために使います。ストーリーポイントなどの主観的な見積もり単位ではなく、完了までの稼働日数を扱います。

## 対象ユーザーと利用場面

エンジニアリングマネージャー、テックリード、チームが納期を予測し、不確実性を関係者に説明します。シナリオの比較や遅延要因の検討、完了後の実績と当初予測の振り返りに使います。

## 機能

- [Predict](predict/prd.ja.md)は想定納期を基準に対数正規分布を作り、完了実績に基づく振り返りに対応します。
- [Simulation](simulation/prd.ja.md)は作業構造、人数制限、作業の発見、手戻りをモデル化し、試行結果から完了期間の分布を求めます。

両機能はリードタイムを稼働日数で表します。現在のカレンダーの扱いは[共通ADR](adr.ja.md)を参照してください。各機能の文書に入力、出力、制約、今後の課題を記載します。

## 共通の対象範囲

稼働日から土日を除きます。祝日やチームごとのカレンダーには現在対応していません。過去のプロジェクトデータを使った自動校正とプロジェクト履歴の保存は今後の課題です。
