## 現在の実装

- `spite predict` コマンドを実装済み。
- 対数正規分布による最善・通常・最悪の3シナリオを計算・表示する。
- 開発中・これから開発する案件の予測と、終了済み案件の振り返りを扱う。
- 過去案件のデータセットを読み込んで係数や分布を推定する機能は未実装。
- SQLite等による記録、祝日対応、スプライス分布、Weibull分布も未実装。

## CLI

```bash
uv run spite predict --start-date YYYY-MM-DD --deadline YYYY-MM-DD [オプション]
```

- `--start-date`: 開発開始日。
- `--deadline`: 当初の想定納期。開始日から数えた稼働日数を通常シナリオのピーク(mode)とする。
- `--best-factor`: 最善シナリオの係数。通常ピークに掛ける。既定値 `0.8`。
- `--worst-factor`: 最悪シナリオの係数。通常ピークに掛ける。既定値 `1.5`。
- `--sigma`: 3シナリオ共通の対数正規分布の幅。既定値 `0.5`。
- `--actual-end-date`: 任意。実際の開発終了日。指定時は終了済み案件の振り返りを追加する。開始日と同日またはそれ以降を指定できる。
- `--output <path>`: グラフを画像に保存。
- `--show`: matplotlibでグラフを表示。`--output`との併用可。
- `--distribution` / `-d`: 現在選べるのは `lognormal` のみ。既定値も `lognormal`。

`--deadline` は開始日より後の稼働日になる必要がある。係数は `0 < best-factor < 1`、`worst-factor > 1` を要求する。σは正の有限値でなければならない。

### 予測モード

`--actual-end-date` を省略すると、3つの分布のP50・P80・P90を稼働日数と日付で表示する。デフォルトではターミナルにASCIIグラフを表示し、`--output` または `--show` の指定時はmatplotlibで3分布を重ねて描く。

### 振り返りモード

`--actual-end-date` を指定すると、上記の予測表示に加えて、実績期間を通常シナリオで評価する。

- 実際の期間と当初の想定納期との差を、稼働日数と割合で表示する。
- 通常シナリオの累積分布関数(CDF)から、実績のパーセンタイルを表示する。
- 通常シナリオのP90との差も表示する。
- 実績がP99.9を超える場合は「P99.9超相当」とし、実績以降に完了する確率を生存関数(SF)で表示する。
- グラフの横軸を実績期間まで広げ、実績位置に目印を表示する。
- 最善・最悪シナリオもグラフに表示するが、数値による振り返り評価は通常シナリオを基準とする。

1件の終了済み案件は、現在の仮定に照らして振り返るために使う。1件の実績から係数・σを自動調整する機能ではない。複数案件を用いた校正は将来の課題。

## 分布と係数

期間は稼働日数で計算する。想定納期までの稼働日数を `D`、最善係数を `b`、最悪係数を `w` とすると、各分布のピークは次のとおり。

```text
最善: D × b       (既定 b = 0.8)
通常: D            (想定納期)
最悪: D × w       (既定 w = 1.5)
```

各ピーク `mode` と共通の `sigma` から対数正規分布を作る。対数正規分布は

```text
mode = exp(mu - sigma²)
mu   = ln(mode) + sigma²
```

の関係なので、実装は `src/spite/params.py` の `params_from_mode_and_sigma()`。
P50・P80・P90およびCDF/SFは `scipy.stats.lognorm` を使って計算する。

0.8、1.5、0.5はいずれも現時点の仮定であり、実証済みの普遍的な値ではない。将来は係数を固定せず、入力要因や複数案件の実績を使うシミュレーション・校正に置き換える構想。

## 稼働日と日付

- `src/spite/businessdays.py` で土日のみを非稼働日として扱う。祝日は未対応。
- 入力日付を開始日からの稼働日数へ変換する処理は `business_days_between()`。
- P値の日数を日付に戻す処理は `add_business_days(start_date, round(days))`。
- `business_days_between()` は開始日を0日として数え、終了日までの日付を走査する。終了日が土日の場合、土日自体は稼働日数に加えない。
- 日付から日数への変換と、整数の稼働日数から日付への変換では丸め方が異なる点に注意する。

## ファイル構成

```text
src/spite/
├── __init__.py       # CLI main の公開
├── cli.py            # 引数、入力検証、3シナリオ計算、レポート
├── params.py         # 対数正規分布パラメータと係数の既定値
├── businessdays.py   # 土日を除く稼働日計算
├── lognormal.py      # scipyによるPDF、分位点、CDF、SF、統計量
└── render.py         # ASCII / matplotlib描画、日付表、実績マーカー
```

Pythonは `.python-version` および `pyproject.toml` で3.13.15系を指定する。依存関係はnumpy、scipy、matplotlib。実行は `uv run spite predict ...` を想定。
